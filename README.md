
# 🚑 Ambulans Gratis Abu Dzar

Website informasi layanan Ambulans Gratis Abu Dzar yang bertujuan memudahkan masyarakat dalam memperoleh informasi layanan ambulans, dokumentasi kegiatan sosial, serta informasi donasi.

## 🌐 Tentang Website

Website ini dikembangkan untuk mendukung digitalisasi layanan sosial Ambulans gratis Abu Dzar, khususnya dalam penyampaian informasi mengenai layanan antar jemput pasien dan jenazah.

## ✨ Fitur Website

- Informasi layanan Ambulans Gratis Abu Dzar
- Informasi kontak dan lokasi layanan
- Galeri dokumentasi kegiatan dengan slideshow foto
- Informasi rekening donasi
- QR Code dan QRIS untuk donasi
- Tombol salin nomor rekening
- Tampilan responsif untuk desktop dan mobile

## 🛠️ Teknologi

- HTML5
- CSS3
- JavaScript
- Vercel (Deployment)

## 🚀 Menjalankan Website

1. Clone repository ini.
2. Buka folder project.
3. Jalankan file `index.html` menggunakan browser.
